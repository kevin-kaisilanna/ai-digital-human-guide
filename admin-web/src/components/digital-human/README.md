# DigitalHuman 数字人配置组件 (PRD 4.2.2)

- `PreviewPanel.vue` — 左侧预览区（实时展示当前配置的数字人形象）
- `ConfigTabs.vue` — 配置面板 Tab 切换（外观/服装/声音/背景）
- `AppearancePanel.vue` — 外观配置（性别/发型/脸型选择）
- `ClothingPanel.vue` — 服装配置（汉服/唐装/民族/现代风格选择）
- `VoicePanel.vue` — 声音配置（声线列表 + 试听按钮）
- `BackgroundPanel.vue` — 背景配置（预设图选择 + 自定义上传）
