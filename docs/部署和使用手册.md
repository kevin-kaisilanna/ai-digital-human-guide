# 景区导览 AI 数字人 — 部署和使用手册

> 软件杯 A5 赛题 | 版本 v1.0 | 2026年7月

## 一、系统概述

本系统是一套完整的景区导览 AI 数字人解决方案，包含：
- **游客端** (visitor-app)：面向游客的 AI 数字人导游交互界面，支持语音/文字问答
- **管理后台** (admin-web)：面向景区管理员的运营管理平台
- **后端服务** (server)：FastAPI 业务 API + RAG 知识检索 + 数据分析
- **数字人引擎** (digital-human)：Unity WebGL 3D 数字人 + TTS 语音合成
- **大模型驱动的 Unity 3D 数字人全栈交互** (affiliate-project)：Unity WebGL 3D 数字人 + LLM生成 + STT + TTS 语音合成

## 三、快速部署

### 3.1 获取工程文件

将 `01-产品源代码和可执行文件/` 目录下的工程文件（`action/`）整体复制到目标机器任意目录。

> **推荐**：如提交包中包含 `action-可执行文件/`（已预装依赖），可直接使用，跳过 3.2~3.3 的依赖安装步骤。

### 3.2 后端部署

本系统包含两个后端服务，共用同一个 Python 虚拟环境。

```bash
# 1. 进入后端目录
cd server

# 2. 创建 Python 虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 初始化数据库（预置 74 条景区知识）
python scripts/seed.py
```

安装完成后，双击 `server/run.bat` 启动 FastAPI 后端（端口 8001）。

AvatarServer 同理，双击 `affiliate-project/AvatarServer/run.bat`（端口 8000）。

### 3.3 前端部署

```bash
# 游客端
cd visitor-app
npm install

# 管理后台
cd admin-web
npm install
```

安装完成后，分别双击各目录下的 `run.bat` 启动对应前端。

### 3.4 启动方式

**统一起动**：双击 `scripts/run.bat`，自动打开 4 个终端窗口启动全部服务。

**单独启动**：各服务目录下均有独立 `run.bat`：

| 双击 | 服务 | 端口 |
|------|------|------|
| `server/run.bat` | FastAPI 后端 | :8001 |
| `affiliate-project/AvatarServer/run.bat` | AvatarServer | :8000 |
| `visitor-app/run.bat` | 游客端 | :5173 |
| `admin-web/run.bat` | 管理后台 | :5174 |


### 3.5 访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 游客端 | http://localhost:5173 | AI 数字人导游交互界面 |
| 管理后台 | http://localhost:5174 | 管理员运营平台 |
| API 文档 | http://localhost:8001/docs | Swagger 接口文档 |
| AvatarServer | http://localhost:8000 | 数字人 LLM / STT / TTS |
| 健康检查 | http://localhost:8001/api/health | 服务状态 |


## 四、游客端使用指南

### 4.1 对话交互

1. 打开游客端 → 数字人"小云"主动打招呼
2. **文字输入**：底部输入框打字 → 按 Enter 或点击发送
3. **语音输入**：长按 🎤 按钮说话 → 松开发送
4. AI 回答时：数字人表情随内容变化，语音播报回答
5. **快捷提问**：点击预设问题按钮快速咨询

1. 点击底部导航「路线推荐」
2. 选择兴趣标签：历史人文 / 自然风光 / 亲子游
3. 浏览推荐路线卡片 → 点击进入详情
4. 查看景点时间轴、讲解要点、预计时长

### 4.3 典型问题示例

- "灵山大佛有多高？"
- "九龙灌浴几点开始？"
- "有什么推荐的游览路线？"
- "门票多少钱？"
- "附近有卫生间吗？"

## 七、常见问题

**Q: 双击 `run.bat` 后窗口一闪而过？**
A: 可能是编码或路径问题，在项目根目录打开命令提示符，手动执行 `scripts\run.bat` 查看错误信息。

**Q: `run.bat` 提示"虚拟环境未找到"？**
A: 说明 `server\venv\` 目录不存在。请先按 3.2 节步骤创建虚拟环境并安装依赖。

**Q: 启动后端报错 `ModuleNotFoundError`？**
A: 确保已激活虚拟环境并执行 `pip install -r requirements.txt`。

**Q: AvatarServer 启动失败？**
A: AvatarServer 与 FastAPI 后端共用 `server\venv\` 虚拟环境，确认 `pip install -r requirements.txt` 已包含 Django 等依赖。也可单独执行 `pip install django djangorestframework`。

**Q: 游客端无法连接后端？**
A: 检查两个后端是否都已启动——FastAPI（http://localhost:8001/api/health）和 AvatarServer（http://localhost:8000）。同时检查 visitor-app 的 Vite 代理配置。

**Q: AI 不回答或回答很慢？**
A: 在 `.env` 中设置 `MOCK_MODE=true` 启用离线 Mock 模式，使用预制回答。

**Q: TTS 语音不播放？**
A: Chrome 需要用户先与页面交互（点击任意位置）后才能播放语音。

**Q: 如何构建 Android APK？**
```bash
cd visitor-app
npm run build
npx cap sync
npx cap open android
# 在 Android Studio 中选择 Build → Build Bundle(s) / APK(s) → Build APK(s)
```
