# API 路由定义

- `chat_routes.py` — POST /api/chat/send, GET /api/chat/history/{session_id}
- `knowledge_routes.py` — CRUD /api/knowledge, POST /api/knowledge/upload
- `analytics_routes.py` — GET /api/analytics/dashboard, GET /api/analytics/reports
- `digital_human_routes.py` — GET/PUT /api/digital-human/config
- `user_routes.py` — POST /api/auth/login, GET /api/user/profile
